# Dynamic-Scheduler
TPFxSPAM Induction Project<hr>
✨Key Features<br>
• Smart Resizing Algorithm: Automatically shrinks tasks from "Ideal" to "Minimum" duration to fit your total available time.<br>
• Priority Intelligence: When time is reduced, the system intelligently shrinks "Low" priority tasks first, preserving "High" priority commitments.<br>
• Chaos Button: A "stress-test" feature that drops available time by 30 minutes to demonstrate real-time schedule adaptation.<br>
• Visual Feedback System: Uses color-coded status banners—Green for a successful fit and Red for time deficits—to provide immediate clarity.
