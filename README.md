# Dynamic-Scheduler
TPFxSPAM Induction Project<hr>

✨Key Features<br>
<br>
• Smart Resizing Algorithm: Automatically shrinks tasks from "Ideal" to "Minimum" duration to fit your total available time.<br>
• Priority Intelligence: When time is reduced, the system intelligently shrinks "Low" priority tasks first, preserving "High" priority commitments.<br>
• Chaos Button: A "stress-test" feature that drops available time by 30 minutes to demonstrate real-time schedule adaptation.<br>
• Visual Feedback System: Uses color-coded status banners—Green for a successful fit and Red for time deficits—to provide immediate clarity.<br><hr>

⚙️ Installation
1. clone the repository: git clone https://github.com/pranayjain-13/Dynamic-Scheduler.git
2. Navigate into project directory: cd Dynamic-Scheduler
3. Install the dependencies: npm install
4. Start the development server: npm run dev (if it doesnt work then try: npm start)
5. If it shows white screen then try refreshing the page
<hr>

🧪 How to Use
1. Add Tasks: Input a title, priority, and both Ideal and Minimum time requirements.
2. Set Available Time: Use the input field to set your total minutes for the day. Watch the tasks automatically resize based on priority.
3. Test the Chaos Button: Click the Chaos Button to see how the app reacts to a sudden 30-minute reduction in your schedule.
4. Monitor Feedback:<br>
• Green Banner: Appears when your tasks fit the schedule.<br>
• Red Banner: Appears if the available time is less than the total minimum required.
